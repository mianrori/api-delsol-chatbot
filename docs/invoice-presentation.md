Los presentadores deterministas de saldos y facturas generales empiezan por el resultado, identifican al cliente una vez cuando el alcance lo demuestra y reducen las columnas a las útiles. Una página con un solo cliente no acredita que todo el resultado le corresponda. Se conservan serie y número disponibles, cada fila, los importes y enlaces autorizados; nunca se deduce la serie de factura de una referencia de contrato.

La deuda cancelada conserva el vencimiento y el cero, sin presentar mora actual ni inferir cuándo se pagó. También se tratan los resúmenes por vencimiento con etiquetas temporales neutrales. Las advertencias son breves y condicionadas: duplicados, identidad incompleta, deuda desconocida, fechas inválidas o acceso parcial. No se habilitan sumas ni se deduplican registros. La paginación habla de registros y ofrece continuar solo con `hasMore`.

Las monedas comerciales se muestran únicamente cuando el código o símbolo informado las acredita. Un código interno no se traduce mediante una equivalencia supuesta; un `$` aislado no acredita USD. El resumen actual puede entregar solo códigos internos sin denominación: en ese caso se indica «Moneda no informada», manteniendo cada grupo e importe separado. No se cambia la consulta para obtener etiquetas nuevas. No se afirma ausencia en otras monedas a partir de una página.

El prompt incorpora los mismos criterios para las respuestas no deterministas, incluidas las facturas en resumen. La redacción de esos casos no fue certificada con un modelo real. Los valores restaurados del presentador general, incluidos nombres y enlaces PDF, se protegen antes de guardar la respuesta en el historial, con la restauración habitual al entregar la respuesta. No se publican ni consultan PDF reales.

[Ejemplos antes/después](invoice-presentation-examples.md): pendientes, deuda cancelada, duplicados y facturas generales con acceso parcial. Son datos sintéticos, no filas de Oracle ni resultados de negocio. Se ejecutaron ambos presentadores sobre el mismo resultado; el «antes» corresponde a `9aaecaa`.
